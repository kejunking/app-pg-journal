# app-pg-journal

## 项目简介

本仓库用于归档和发布多个独立的 HTML 页面。这些页面内容多样，涵盖不同主题与用途，以静态 HTML 文件形式存放，便于浏览、分享与版本管理。仓库本身不绑定任何特定域名或网站，仅作为页面集合的存储与展示空间。

## 目录说明

```
.
├── README.md              # 本文件
├── index.html             # 可选：页面索引或导航页
├── page1/                 # 示例：某类页面文件夹
│   ├── index.html
│   └── assets/
└── page2/                 # 示例：另一类页面文件夹
    ├── index.html
    └── assets/
```

- 各页面独立存放在对应文件夹内，避免相互影响。
- 页面所需的样式、脚本、图片等资源建议统一放置在 `assets` 子目录中。
- 根目录下的 `index.html` 为可选入口，可用来列出所有归档页面。

## 页面归档说明

- 所有页面均为纯静态 HTML，不依赖后端服务。
- 页面内容由作者自主制作或收集整理，仅供存档与展示。
- 每个页面应自包含、可独立访问，建议遵循基本 HTML 规范。
- 若引用外部资源（如字体、库），建议托管在本仓库或使用可靠 CDN。

## 维护说明

- 本仓库由作者不定期更新，新增或修改页面会以提交记录形式体现。
- 欢迎通过 Issues 提出建议或报告页面显示问题。
- 不建议直接在此仓库中存放敏感信息或大体积二进制文件。
- 若需引用或分发本仓库中的页面，请保留原始出处说明。
